A shirt and a T-shirt can look remarkably similar in a 28 × 28 image. I wanted to see where logistic regression drew the boundary between them, and what happened to its accuracy when that boundary was removed.

Research Question#

How accurately can a linear classifier distinguish the ten Fashion-MNIST categories using pixel intensities alone? I examined two aspects of this question: whether tuning improved classification under the original labels, and which distinctions remained difficult after tuning. Frequent confusion between shirts and T-shirts subsequently motivated a separate experiment with a revised label scheme.

Dataset and Image Representation#

Fashion-MNIST contains 60,000 training images and 10,000 test images across ten clothing categories [1]. Each image measures 28 × 28 pixels. I represented each observation as a vector of 784 intensities and kept the garment label as the outcome. I estimated each pixel’s mean and scale from the training set and applied the same transformation to the test images.

Each class has 1,000 examples in the test set. This makes the confusion matrix particularly informative: a row gives both the number of correctly identified garments in a category and the destinations of its errors.

Flattening keeps the value of every pixel and gives each location a consistent column in the dataset. It does change how the model can use those values. Consider the dark gap between a sleeve and the body of a garment. In one image the gap might occupy column 5, and in another it might occupy column 6. A weight learned for the first location applies only there. The model can learn useful weights at both positions, but their relationship has to be inferred from the training examples. That makes this representation a reasonable starting point for coarse silhouettes and an interesting test for details such as collars and sleeves.

The equal class counts also give the overall score a convenient interpretation. Each class contributes one tenth of test accuracy. An improvement of ten percentage points in shirt recall, with every other class unchanged, would move the overall score by just one percentage point. This is why I report the overall benchmark alongside individual class results. An apparently modest change in the benchmark can correspond to a meaningful change for a particular garment.

Model Fitting and Evaluation#

I fitted a baseline logistic regression model and evaluated twelve combinations of regularisation strength and numerical solver using five-fold cross-validation. The highest mean validation accuracy was 85.72%, with the L-BFGS solver and inverse regularisation strength C = 0.01. I refitted that configuration on the training set and evaluated it on the test images.

The baseline test accuracy was approximately 84%. The diagonal of the tuned model’s test confusion matrix sums to 8,585 correct predictions, giving a test accuracy of 85.85% [2, p. 13]. The cross-validation and test figures describe separate evaluations.

What Changed during Tuning?#

The table shows mean validation accuracy across five folds, as reported on page 12. Each row fixes the amount of regularisation so the two optimisation algorithms can be compared on the same footing.

Reading down the L-BFGS column, accuracy first increases and then falls as the penalty weakens. Between C = 0.01 and C = 100 the difference is 2.03 percentage points. Reading across the best row, changing the solver moves the mean by only 0.01 percentage points at the reported precision. Both solvers picked out the same region of the grid. On the evidence of this experiment, the choice of regularisation strength deserves more attention than the narrow ranking of the two optimisers.

There is a detail I would change in a replication. The original notebook standardised the complete training matrix before passing it to five-fold cross-validation. Each validation fold therefore contributed to the pixel means and scales used during model selection. The official test set stayed outside this calculation. To estimate validation performance more strictly, I would place the scaler and estimator inside a pipeline and fit both anew within each training fold [6]. The table records the original experiment. A fold-wise rerun would produce its own estimates.

Fitting the Selected Model#

This excerpt starts with the two Fashion-MNIST CSV files used in the report. It reproduces the final fitting step with the selected settings. Fitting the scaler on the training images keeps information from the test images out of the transformation.

python
import pandas as pd
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix
from sklearn.preprocessing import StandardScaler

train = pd.read_csv("fashion-mnist_train.csv")
test = pd.read_csv("fashion-mnist_test.csv")
features = train.columns.drop("label")

scaler = StandardScaler()
X_train = scaler.fit_transform(train[features])
X_test = scaler.transform(test[features])

model = LogisticRegression(C=0.01, solver="lbfgs", max_iter=3500)
model.fit(X_train, train["label"])
predicted = model.predict(X_test)
cm = confusion_matrix(test["label"], predicted, labels=range(10))

The model gives each clothing class a score built from a weighted sum of the standardised pixel values. A smaller C applies stronger regularisation to those weights. Cross-validation helps choose its strength; the held-out confusion matrix answers a different question: which garments does the fitted classifier actually confuse?

Error Patterns among Shirts#

Of the 1,000 images labelled shirt, the tuned model identified 602 correctly. It assigned 154 to T-shirt/top, 102 to pullover, and 88 to coat. These three destinations account for 344 of the 398 shirt errors. The errors were therefore concentrated among a small set of garment categories.

To interpret that row, the denominator matters. Reading across row 6 gives the fraction of actual shirts the classifier recovered. Reading down column 6 gives the fraction of its shirt predictions that were correct. On the reported test set those values were about 60% and 66%, respectively. Inspecting only the examples predicted as shirts would miss the 398 shirts assigned elsewhere.

What an Error Gallery Can Establish#

The photographs in Figure 1 were selected because the model was wrong. They are useful for inspecting the kinds of shapes that gave rise to a mistake, but they say little about how often those shapes occur among correctly predicted garments. For example, a prominent sleeve in one misclassified shirt might also occur in hundreds of correctly recognised shirts. Establishing a systematic association would require comparing both sets. One useful design would pair errors with correctly classified images of the same true class and similar brightness, then inspect the pairs without showing their predictions.

The matrix provides another check on what the gallery appears to show. The tuned classifier correctly recognised 973 of 1,000 trousers and 947 of 1,000 bags, compared with 602 shirts. All three classes were evaluated with the same feature representation, estimator, and number of test examples. The aggregate accuracy therefore conceals substantial variation in how informative those pixels are for different distinctions. This observation motivated a closer examination of the geometry of the shirt and T-shirt examples.

How Do Shirts and T-Shirts Occupy the Feature Space?#

I selected the training examples with labels 0 and 6 and examined two projections of their pixel vectors. The labels supply the colours in the plots. Neither projection used those colours to choose where to place a point. This matters because the question was whether the structure of the images themselves would reveal a distinction that the classifier struggled to recover.

A Linear View with PCA#

Principal component analysis finds directions that successively account for the greatest variation in the inputs [3]. Figure 2 places each garment according to its scores on the first two such directions. Follow the lower edge of the cloud from left to right: many T-shirts and shirts occupy the same band. Farther up the second component, shirts become more prominent. A horizontal cut across this picture would capture part of the distinction, while still leaving a substantial mixed region.

A projection that retains only two directions discards information in the remaining components. A subtle detail could have little influence on overall variance and still be useful for identifying a shirt. The overlap in Figure 2 consequently supports a limited claim: these two leading directions do a poor job of separating the classes throughout the sample. Whether a linear decision boundary can separate them in the original 784 dimensions is a different question. The held-out classifier provides more direct evidence about the particular linear model fitted here.

A Neighbourhood View with t-SNE#

I also examined the same two classes using t-distributed stochastic neighbour embedding, or t-SNE [4]. Here the useful comparison is local. Pick a point and look at the colours of its neighbours. In the upper part of Figure 3 there are broad groups dominated by orange. In the lower part, blue predominates in several pockets, interspersed with orange. This pattern is consistent with some garment types having distinctive local structure even where the PCA projection was crowded.

The apparent gap between two groups in a t-SNE plot can change with the perplexity or initialisation [5]. Measuring the distance between the centres of the orange and blue regions on this plot would therefore give a misleading impression of precision. A more informative follow-up would select points from mixed and single-colour neighbourhoods, recover their source images, and inspect the garments side by side. That would connect the visual pattern to an image characteristic a reader can actually recognise.

Together, the projections motivate a hypothesis about the original errors. A linear combination of pixels may distinguish several common silhouettes while overlooking finer local differences. Testing that hypothesis requires a predictive comparison on the ten original labels. A nonlinear classifier evaluated on held-out images could test it. A visually cleaner embedding alone cannot settle it.

Interpreting the Merged-Label Experiment#

I then combined shirts and T-shirts into a single class and retrained the model. This changed which predictions qualified as correct. To interpret the reported result, I also calculated a baseline for the revised task directly from the original confusion matrix.

Model and evaluation Correct predictions Test accuracy
Tuned model, original ten classes 8,585 85.85%
Original predictions rescored under nine classes 8,839 88.39%
Retrained model, nine classes 8,793 87.93%

The middle row is a retrospective calculation for this article. The original model called 154 shirts T-shirts and 100 T-shirts shirts. Rescoring those predictions credits both groups, adding 254 correct results. On the revised task, the original predictions therefore yielded 46 more correct classifications than the retrained model on this test set.

The same matrix can score both tasks. Its diagonal counts exact matches. Once classes 0 and 6 share a label, precisely two off-diagonal cells also count as matches:

python
total = cm.sum()
exact = cm.trace()
new_matches = cm[0, 6] + cm[6, 0]

print(f"Ten-class accuracy: {exact / total:.2%}")
print(f"Same predictions after merging: {(exact + new_matches) / total:.2%}")

This baseline holds every pixel weight and prediction fixed. It isolates the effect of changing the scoring rule before any decision about refitting.

Conclusion#

Tuning improved overall accuracy on the ten-class task, while shirt recall remained substantially below the aggregate result. Inspecting individual errors located a specific class boundary that warranted investigation. The merged-label experiment also illustrates how a change in the definition of the target can affect the evaluation as much as a change in the model.

The intended application determines whether the shirt distinction should be retained. A follow-up study could ask independent reviewers to label ambiguous garments, fix the class definitions in advance, and evaluate both approaches on fresh images. This would address a limitation of the present analysis: the same test set informed the decision to examine and merge the two categories.

Which Experiment Should Come Next?#

My report proposed three lines of investigation [2, pp. 21–22]. The first is to change the decision boundary while keeping the data and category definitions fixed. I would start with a kernel support vector machine as a comparison with the linear baseline. Both models should see the same training splits and be assessed on the same test images. Recording shirt recall alongside overall accuracy would reveal whether any improvement reaches the class that motivated the experiment. Per-image predictions would also show whether the new model corrects old errors at the expense of introducing different ones.

A second line of investigation is to change the representation. The report suggests feature selection, PCA, and learned representations such as autoencoders. A model using a reduced set of principal components would make a useful controlled experiment: fit PCA within each training fold, choose the retained dimension on validation data, and keep the classifier fixed. If reducing dimension helps, some of the original variation may have been unhelpful for prediction. If shirt recall deteriorates, the discarded components may contain details that matter for this specific boundary.

The third is to treat similar garments as a local classification problem. A first-stage model could identify a broad upper-body clothing group, followed by a specialist for the distinctions within it. Evaluation would need to count mistakes at both stages. An accurate specialist cannot recover a shirt that the first stage sent elsewhere. Small translations or other training-only augmentations could also test the sensitivity to pixel alignment described earlier. I would introduce one change at a time and retain the same evaluation protocol across these experiments.

For the original research question, the strongest result is the combination of a useful linear baseline and an unusually well-localised limitation. Regularisation improved the benchmark, the confusion matrix identified the garments that remained difficult, and the projections suggested where a richer representation might help. The next substantive gain would be better discrimination of those garments under the original labels, demonstrated on previously unseen examples.
